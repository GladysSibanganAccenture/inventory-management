Filter System

4 global filters managed by useFilters() singleton. Applied as query params on every API call. Views watch for changes and re-fetch automatically.

Time Period  month
all • 2025-01 through 2025-12 • Q1–Q4 2025
Supports YYYY-MM and quarter format. Inventory view excluded (no time dimension).
Warehouse  warehouse
all • San Francisco • London • Tokyo
Applies to Inventory, Orders, Dashboard.
Category  category
all • Circuit Boards • Sensors • Actuators • Controllers • Power Supplies
Order Status  status
all • Delivered • Shipped • Processing • Backordered
Applies to Orders and Dashboard only.
